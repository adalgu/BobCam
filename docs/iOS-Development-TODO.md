# BobCam iOS 개발 투두리스트

## 📋 프로젝트 개요

- **목표**: iPhone 13 Pro에서 실시간 립 트래킹 기반 비디오 자동 제어 앱 개발
- **기술 스택**: Swift + SwiftUI + Vision Framework + AVFoundation + Core ML
- **성능 목표**: 200ms 지연시간, 70% 정확도, 20분당 15% 배터리 소모
- **현재 진행률**: 25% (Phase 1 완료)
- **활성 페이즈**: Phase 2 - 알고리즘 정확도 향상

---
