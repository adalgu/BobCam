# Product Context: 밥잘먹어YO (Bob-Cam)

## 1. Problem to Solve

Users, potentially children or individuals needing meal monitoring, may not eat consistently or may get distracted during meals. This can lead to poor eating habits. A system is needed to gently encourage and track eating behavior without being intrusive. The initial prototype suffered from instability and unreliable detection, making it unsuitable for real-world use.

## 2. How It Should Work

The application should function as a "smart" video player that rewards eating behavior.

*   **Monitoring**: The application uses the computer's webcam to monitor the user's face.
*   **Detection**: It analyzes the user's mouth movements to determine if they are actively eating. The detection should be smart enough to distinguish between eating and other activities like talking.
*   **Feedback**: When eating is detected, a pre-selected video (e.g., a cartoon) plays as a positive reinforcement. When the user stops eating for a certain period, the video should pause, gently prompting them to continue their meal.
*   **User Experience**: The experience should be seamless and non-frustrating. The system should feel responsive and intelligent, not like a simple on/off switch. The GUI should be clean and intuitive, providing clear feedback about the system's status.

## 3. User Goals

*   To have a tool that encourages consistent eating during mealtimes.
*   To monitor meal progress without constant human supervision.
*   To use a stable and reliable application that doesn't crash or behave erratically.
