### 1. **Settings Not Persisted** - `SettingsView.swift:11`
- **Problem**: Debug mode, performance metrics, and accuracy display toggles reset on every app launch
- **Impact**: User settings completely non-functional
- **Fix Required**:
```swift

@AppStorage("isDebugModeEnabled") private var isDebugModeEnabled = false
@AppStorage("showPerformanceMetrics") private var showPerformanceMetrics = false
@AppStorage("showAccuracyDisplay") private var showAccuracyDisplay = false
```

### 2. **Data Loss Risk** - `VideoSelectionService.swift:178`
