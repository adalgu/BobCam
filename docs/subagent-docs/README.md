## 🎯 각 도구의 역할

| 도구 | 주요 역할 | 강점 | 활용 시점 |
|------|----------|------|----------|
| **Gemini** | 창의적 아이디어 생성 | 브레인스토밍, 콘텐츠 제작 | 기획 단계, 창의적 해결책 필요시 |
| **Claude** | 체계적 분석 및 설계 | 코드 분석, 아키텍처 설계 | 문제 분석, 시스템 설계 단계 |
| **Zen MCP** | 고급 추론 및 검증 | 워크플로우 관리, 의사결정 | 복잡한 판단, 다단계 작업시 |
| **Codex** | 빠른 구현 및 자동화 | 코드 생성, 프로토타이핑 | 구현 단계, 반복 작업시 |

## 🚀 시작 가이드

1. **[전체 개요](./01-subagent-overview.md)** 먼저 읽기
2. 필요한 도구의 개별 가이드 학습
3. **[협업 패턴](./06-collaboration-patterns.md)**으로 고급 활용법 익히기

## 💡 활용 팁

- **단일 작업**: 해당 도구의 개별 가이드 참조
- **복합 작업**: 협업 패턴에서 적절한 워크플로우 선택
- **최적화**: 작업 특성에 따라 도구 조합 실험
