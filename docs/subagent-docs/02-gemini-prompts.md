# Gemini CLI 프롬프트 예시집

## 기본 정보
- **Agent**: Gemini CLI Agent
- **모델**: gemini-2.5-pro (기본값)
- **특징**: 창의적 사고, 멀티모달 처리, 빠른 응답
- **강점**: 아이디어 생성, 콘텐츠 제작, 창의적 문제 해결

## 기본 사용법

```bash
# 기본 프롬프트
gemini -p "your prompt here"

# 모델 지정
gemini -p "your prompt" -m "gemini-2.5-pro"

# 대화형 모드
gemini -i "initial prompt"

# YOLO 모드 (자동 승인)
gemini -p "your prompt" -y

# 디버그 모드
gemini -p "your prompt" -d
```

## 카테고리별 프롬프트 예시

### 1. 창의적 콘텐츠 생성

#### 블로그 포스트 아이디어
```bash
gemini -p "AI와 개발자의 협업을 주제로 한 블로그 포스트 5개 아이디어를 창의적으로 제안해주세요. 각각 독특한 관점과 흥미로운 제목을 포함해주세요."
```

#### 마케팅 카피 생성
```bash
gemini -p "새로운 개발자 도구 'CodeZen'을 위한 마케팅 카피를 작성해주세요. 핵심 가치는 '개발 생산성 향상'과 'AI 협업'입니다. 3가지 다른 톤으로 제안해주세요."
```

#### 스토리텔링

## 고급 활용 팁

### 1. 다단계 프롬프팅
```bash
# 1단계: 아이디어 생성
gemini -p "모바일 앱 개발의 혁신적인 접근 방법 5가지 제안"

# 2단계: 세부 발전 (이전 결과를 바탕으로)
gemini -p "첫 번째 아이디어를 구체적인 구현 계획으로 발전시켜주세요"
```

### 2. 역할 기반 프롬프팅
```bash
gemini -p "당신은 창의적인 제품 기획자입니다. 개발자의 생산성을 10배 향상시킬 수 있는 혁신적인 도구를 상상해서 기획해주세요."
```

### 3. 제약 조건 활용
```bash
gemini -p "예산 1만 달러, 개발 기간 3개월이라는 제약 하에서 개발자 커뮤니티에 임팩트를 줄 수 있는 프로젝트를 창의적으로 제안해주세요."
```

### 4. 관점 전환
```bash
gemini -p "개발자가 아닌 일반 사용자의 관점에서 프로그래밍을 더 쉽게 만들 수 있는 방법을 창의적으로 제안해주세요."
```

## 결과 활용 방법

### 1. 다른 Agent와의 협업
```bash
# Gemini로 아이디어 생성 후 Claude로 기술적 검증
gemini -p "혁신적인 개발 도구 아이디어 생성" > gemini_ideas.txt
claude -p "다음 아이디어들의 기술적 타당성을 분석해주세요: $(cat gemini_ideas.txt)"
```

### 2. 반복적 개선
```bash
# 초기 아이디어 → 피드백 → 개선안
gemini -p "초기 아이디어: [내용]을 더 창의적이고 실용적으로 개선해주세요"
```

### 3. 다양한 관점 생성
```bash
# 동일한 주제에 대해 여러 관점에서 접근
gemini -p "기술적 관점에서 [주제] 분석"
gemini -p "사용자 관점에서 [주제] 분석"  
gemini -p "비즈니스 관점에서 [주제] 분석"
```

이 예시들을 활용하여 Gemini CLI의 창의적 잠재력을 최대한 활용해보세요!
