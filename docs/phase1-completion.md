### 씹기 패턴 감지
- **FFT 기반 주파수 분석**: 0.5-3Hz 대역에서 씹기 리듬 감지
- **신뢰도 점수**: 0-1 범위의 정량적 측정
- **다중 특징 융합**: 턱 높이, 너비, 각도 변화 종합 분석

### 복합 판단 시스템
```python
# 우선순위 기반 신뢰도 계산
if chewing_pattern and lips_moving:
    confidence = 0.95, method = "combined"
elif chewing_pattern:
    confidence = 0.8, method = "jaw"  
elif lips_moving and jaw_moving:
    confidence = 0.75, method = "combined"
```

## 🐛 알려진 제한사항

### 1. 환경 의존성
- **조명**: 너무 어두우면 랜드마크 정확도 감소
- **각도**: 정면이 아닌 각도에서 정확도 저하 가능
- **가림**: 손이나 음식이 얼굴을 가리면 감지 실패

### 2. 성능 고려사항
- **CPU 사용량**: 기본 대비 약 15-20% 증가
- **메모리**: 추가 히스토리 버퍼로 약 10MB 증가
- **지연시간**: FFT 계산으로 1-2ms 추가 지연

### 3. 알고리즘 한계
- **개인차**: 턱 움직임 패턴의 개인별 차이
- **학습 필요**: 사용자별 최적 임계값 조정 필요할 수 있음
