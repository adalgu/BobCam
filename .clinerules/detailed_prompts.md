# 세부 프롬프트 모음

이 파일은 Claude Projects의 AI 협력 개발 시스템에서 사용하는 세부 프롬프트들을 포함합니다.
각 프롬프트는 명령어나 특정 상황에서 자동으로 활성화됩니다.

---

## 🗺️ 로드맵 관리 프롬프트 (/roadmap)

### 컨텍스트:

프로젝트 진행 상황을 체계적으로 관리하기 위한 로드맵 문서를 생성하고 관리합니다.

### 입력 지침:

다음 정보를 제공해 주세요:

- 프로젝트 이름 및 주요 목표
- 예상되는 주요 페이즈 목록
- 각 페이즈별 세부 태스크 (가능한 경우)
- 우선순위 및 의존성 정보

### 출력 지침:

`project_roadmap.md` 파일을 다음 구조로 생성하세요:

1. **프로젝트 개요**

   - 프로젝트 이름, 목표, 범위
   - 예상 완료 시기 및 주요 마일스톤

2. **전체 진행 상황**

   - 전체 진행률 (예: 진행률: 35% [7/20 완료])
   - 현재 활성 페이즈
   - 다음 우선순위 태스크

3. **페이즈별 세부 태스크 목록**

   ```markdown
   ## 📋 Phase 1: 프로젝트 설정

   - ❌ 프로젝트 구조 설계
   - 🔄 개발 환경 설정 (2024-07-08 14:30 시작)
   - ✅ 요구사항 분석 (2024-07-08 13:45 완료)

   ## 📋 Phase 2: 핵심 기능 개발

   - ❌ 사용자 인터페이스 설계
   - ❌ 백엔드 API 구현
   ```

4. **상태 표시 규칙**

   - ❌ 미완료
   - 🔄 진행중 (시작 시간 기록)
   - ✅ 완료 (완료 시간 기록)

5. **완료 시간 기록**

   - 각 태스크 완료 시 정확한 타임스탬프 추가
   - 소요 시간 계산 및 기록

6. **변경 히스토리 관리**

   모든 변경사항은 별도 파일에 기록:
   ```markdown
   ## 📝 변경 히스토리
   상세한 변경 로그는 별도 파일을 참조하세요: [📝 change_log.md](./change_log.md)
   ```

7. **다음 우선순위 태스크**
   - 즉시 처리해야 할 태스크 3개
   - 각 태스크의 예상 소요 시간
   - 필요한 사전 작업이나 의존성

### 제약 및 최적화:

- 체크리스트 형태로 관리하기 쉽게 구성
- 각 태스크는 명확하고 측정 가능하게 작성 (완료 조건 명시)
- 정기적인 업데이트가 가능한 구조
- 프로젝트 진행률을 시각적으로 파악 가능
- 태스크 간 의존성을 명확히 표시
- 병목 지점이나 리스크가 있는 태스크는 🚨 표시
- **변경로그 분리 관리**: 모든 변경사항은 `change_log.md`에 별도 기록
- **로드맵 순수성**: 메인 로드맵은 현재 상태와 계획에만 집중
