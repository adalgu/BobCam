## 1. 소개

BobCam은 아이의 식사 행동을 모니터링하고 적절한 피드백을 제공하는 스마트 식사 모니터링 애플리케이션입니다. 아이폰의 카메라를 통해 아이의 얼굴을 인식하고 입 움직임을 추적하여 식사 여부를 판단하며, 이 정보를 안드로이드 태블릿에 전송하여 아이가 식사할 때는 영상을 재생하고 식사를 멈추면 영상을 일시정지합니다.

### 주요 기능
- 실시간 얼굴 감지 및 입 움직임 추적
- 식사 행동 분석
- 블루투스를 통한 기기 간 통신
- 식사 상태에 따른 유튜브 영상 자동 재생/일시정지
- 직관적인 사용자 인터페이스

## 2. 시작하기

### 시스템 요구사항
- **아이폰**: iOS 14.0 이상, 아이폰 13 이상 권장
- **안드로이드 태블릿**: 안드로이드 10.0 이상, 레노버 탭 P11 이상 권장
- 두 기기 모두 블루투스 기능 지원 필요

### 앱 설치
1. 각 기기의 앱 스토어에서 "BobCam" 앱을 검색하여 설치합니다.
2. 앱을 실행하고 필요한 권한(카메라, 블루투스 등)을 허용합니다.

### 초기 설정
1. 두 기기의 블루투스를 활성화합니다.
2. 아이폰과 안드로이드 태블릿에서 BobCam 앱을 실행합니다.
3. 아이폰 앱에서 "태블릿 검색" 버튼을 탭하여 안드로이드 태블릿과 연결합니다.
4. 연결이 성공하면 두 기기 모두에 연결 성공 메시지가 표시됩니다.

## 3. 아이폰 앱 사용법

### 메인 화면
아이폰 앱의 메인 화면은 카메라 뷰와 상태 표시 영역으로 구성되어 있습니다.

### 카메라 설정
1. 아이폰을 아이의 얼굴이 잘 보이는 위치에 설치합니다.
2. 충분한 조명이 있는 환경에서 사용합니다.
3. 아이의 얼굴이 카메라 프레임 안에 완전히 들어오도록 합니다.

### 식사 모니터링
1. 카메라가 아이의 얼굴을 감지하면 화면에 얼굴 윤곽이 표시됩니다.
2. 앱이 아이의 입 움직임을 분석하여 식사 여부를 판단합니다.
3. 아이가 식사를 하면 녹색 표시와 함께 "아이가 밥을 먹고 있어요" 메시지가 표시됩니다.
4. 아이가 식사를 하지 않으면 빨간색 표시와 함께 "아이가 밥을 먹고 있지 않아요" 메시지가 표시됩니다.

### 블루투스 연결
1. "태블릿 검색" 버튼을 탭하여 안드로이드 태블릿을 검색합니다.
2. 연결이 성공하면 "태블릿과 연결되었습니다" 메시지가 표시됩니다.
3. 연결이 끊어지면 "태블릿과 연결이 끊어졌습니다" 메시지가 표시됩니다.

### 테스트 모드
개발 및 테스트 목적으로 수동으로 식사 상태를 전환할 수 있는 기능이 제공됩니다.
1. "식사 시작" 또는 "식사 중지" 버튼을 탭하여 상태를 수동으로 전환합니다.
2. 이 기능은 실제 사용 시에는 숨겨질 수 있습니다.

## 4. 안드로이드 태블릿 앱 사용법

### 메인 화면
안드로이드 태블릿 앱의 메인 화면은 상태 표시 영역, 유튜브 플레이어, 비디오 ID 입력 필드로 구성되어 있습니다.

### 영상 설정
1. 비디오 ID 입력 필드에 유튜브 비디오 ID 또는 URL을 입력합니다.
2. 엔터 키를 누르거나 입력 완료 후 다른 곳을 탭하면 입력한 영상이 로드됩니다.
3. 아이가 좋아하는 영상을 미리 준비해두면 편리합니다.

### 영상 재생 제어
1. 아이폰에서 전송된 식사 상태에 따라 영상이 자동으로 재생되거나 일시정지됩니다.
2. 아이가 식사를 하면 영상이 재생됩니다.
3. 아이가 식사를 멈추면 영상이 일시정지됩니다.

### 블루투스 연결
1. "기기 검색" 버튼을 탭하여 아이폰을 검색합니다.
2. 연결이 성공하면 "기기와 연결되었습니다" 메시지가 표시됩니다.
3. 연결이 끊어지면 "기기와 연결이 끊어졌습니다" 메시지가 표시됩니다.

## 5. 고급 기능

### 캐릭터 인터페이스
화면 가장자리에 위치한 캐릭터 영역은 향후 업데이트에서 아이와 상호작용하는 캐릭터가 추가될 예정입니다. 현재 버전에서는 이 영역이 표시만 되어 있습니다.

### 식사 데이터 분석
향후 업데이트에서는 아이의 식사 패턴을 기록하고 분석하여 부모에게 인사이트를 제공하는 기능이 추가될 예정입니다.

### 크레딧 시스템
향후 업데이트에서는 아이가 식사한 시간에 따라 크레딧을 적립하고, 이 크레딧으로 영상 시청 시간을 관리하는 기능이 추가될 예정입니다.

## 6. 문제 해결

### 연결 문제
- **문제**: 두 기기가 연결되지 않습니다.
- **해결 방법**:
  1. 두 기기의 블루투스가 활성화되어 있는지 확인합니다.
  2. 두 기기가 서로 가까이 있는지 확인합니다(10m 이내 권장).
  3. 앱을 재시작하고 연결 과정을 다시 시도합니다.

### 얼굴 인식 문제
- **문제**: 아이의 얼굴이 인식되지 않습니다.
- **해결 방법**:
  1. 충분한 조명이 있는 환경에서 사용합니다.
  2. 카메라가 아이의 얼굴을 정면으로 볼 수 있도록 위치를 조정합니다.
  3. 아이의 얼굴이 카메라 프레임 안에 완전히 들어오도록 합니다.

### 영상 재생 문제
- **문제**: 영상이 재생되지 않습니다.
- **해결 방법**:
  1. 인터넷 연결 상태를 확인합니다.
  2. 유튜브 앱이 최신 버전인지 확인합니다.
  3. 유효한 유튜브 영상 ID 또는 URL을 입력했는지 확인합니다.
  4. 블루투스 연결 상태를 확인합니다.

### 앱 충돌 문제
- **문제**: 앱이 갑자기 종료됩니다.
- **해결 방법**:
  1. 앱을 재시작합니다.
  2. 기기를 재부팅합니다.
  3. 앱을 재설치합니다.
  4. 문제가 지속되면 지원팀에 문의합니다.

## 7. 자주 묻는 질문(FAQ)

### Q: BobCam 앱은 어떤 원리로 작동하나요?
A: BobCam은 아이폰의 카메라와 머신러닝 기술을 사용하여 아이의 얼굴을 인식하고 입 움직임을 추적합니다. 이를 통해 아이가 식사 중인지 아닌지를 판단하고, 그 정보를 블루투스를 통해 안드로이드 태블릿에 전송하여 영상 재생을 제어합니다.

### Q: 여러 명의 아이가 함께 식사할 때도 사용할 수 있나요?
A: 현재 버전은 한 명의 아이를 모니터링하는 데 최적화되어 있습니다. 향후 업데이트에서 여러 명의 아이를 동시에 모니터링하는 기능이 추가될 수 있습니다.

### Q: 앱이 아이의 개인 정보를 수집하나요?
A: BobCam은 아이의 얼굴 이미지나 개인 정보를 서버에 저장하지 않습니다. 모든 처리는 기기 내에서 이루어지며, 블루투스를 통해 전송되는 정보는 식사 상태와 같은 단순한 데이터만 포함합니다.

### Q: 다른 태블릿이나 스마트폰에서도 사용할 수 있나요?
A: 아이폰 앱은 iOS 14.0 이상을 지원하며, 안드로이드 앱은 안드로이드 10.0 이상을 지원합니다. 다른 기기에서도 이 요구사항을 충족하면 사용할 수 있지만, 최적의 경험을 위해 아이폰 13 이상과 레노버 탭 P11 이상을 권장합니다.

### Q: 앱 사용 중 문제가 발생하면 어디에 문의해야 하나요?
A: 지원 이메일(support@bobcam.com) 또는 웹사이트(www.bobcam.com/support)를 통해 문의할 수 있습니다.
