# BobCam 시스템 아키텍처 설계

## 1. 개요

BobCam은 아이의 식사 행동을 모니터링하고 적절한 피드백을 제공하는 애플리케이션입니다. 본 문서는 아이폰과 안드로이드 태블릿을 연동하여 BobCam을 구현하기 위한 시스템 아키텍처를 설명합니다.

## 2. 시스템 구성

### 2.1 하드웨어 구성
- **아이폰 13**: 카메라 입력 및 얼굴 인식 처리 담당
- **레노버 탭 P11 (안드로이드 태블릿)**: 영상 재생 및 사용자 인터페이스 담당

### 2.2 소프트웨어 구성
- **개발 프레임워크**: Flutter (크로스 플랫폼)
- **블루투스 통신**: universal_ble 라이브러리
- **얼굴 인식**: TensorFlow Lite 또는 ML Kit (Flutter 호환)
- **영상 재생**: YouTube API 또는 내장 비디오 플레이어

## 3. 아키텍처 설계

### 3.1 전체 시스템 구조

```
+------------------+                   +----------------------+
|    아이폰 13     |                   |   레노버 탭 P11      |
|                  |                   |                      |
|  +------------+  |                   |  +----------------+  |
|  | 카메라 모듈 |  |                   |  | 영상 재생 모듈  |  |
|  +------------+  |                   |  +----------------+  |
|        |         |                   |         |           |
|  +------------+  |                   |  +----------------+  |
|  | 얼굴 인식  |  |                   |  | 사용자 인터페이스|  |
|  +------------+  |                   |  +----------------+  |
|        |         |                   |         |           |
|  +------------+  |    블루투스 통신   |  +----------------+  |
|  | 상태 분석  | <-----------------> |  | 상태 수신 모듈  |  |
|  +------------+  |                   |  +----------------+  |
|                  |                   |                      |
+------------------+                   +----------------------+
```

### 3.2 모듈별 기능

#### 3.2.1 아이폰 앱 모듈
1. **카메라 모듈**
   - 실시간 카메라 입력 처리
   - 프레임 캡처 및 전처리

2. **얼굴 인식 모듈**
   - 얼굴 감지 및 랜드마크 추출
   - 입 움직임 추적

3. **상태 분석 모듈**
   - 입 움직임 데이터 분석
   - 식사 행동 판단 (먹고 있음/먹고 있지 않음)
   - 블루투스를 통한 상태 전송

#### 3.2.2 안드로이드 태블릿 앱 모듈
1. **상태 수신 모듈**
   - 블루투스를 통한 상태 수신
   - 상태 변화 감지 및 처리

2. **영상 재생 모듈**
   - YouTube 영상 재생 제어
   - 상태에 따른 재생/일시정지 처리

3. **사용자 인터페이스 모듈**
   - 상태 표시 및 피드백 메시지 출력
   - 설정 및 제어 인터페이스 제공

### 3.3 통신 아키텍처

#### 3.3.1 블루투스 통신 프로토콜
- **통신 방식**: BLE (Bluetooth Low Energy)
- **라이브러리**: universal_ble
- **메시지 형식**: JSON 문자열

#### 3.3.2 메시지 구조
```json
{
  "status": "eating|not_eating",
  "confidence": 0.95,
  "timestamp": 1647234567890
}
```

#### 3.3.3 통신 흐름
1. 아이폰 앱에서 식사 행동 분석
2. 상태 변화 감지 시 블루투스를 통해 메시지 전송
3. 안드로이드 태블릿 앱에서 메시지 수신 및 처리
4. 상태에 따라 영상 재생/일시정지 및 피드백 메시지 표시
