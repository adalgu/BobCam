# BobCam 앱 설치 및 사용 가이드

## 1. 개요

BobCam은 아이의 식사 행동을 모니터링하고 적절한 피드백을 제공하는 애플리케이션입니다. 이 문서는 BobCam 앱의 설치 및 사용 방법을 안내합니다.

## 2. 시스템 요구사항

### 아이폰 (카메라 및 분석 담당)
- iOS 14.0 이상
- 아이폰 13 이상 권장 (전면 카메라 필요)
- 블루투스 기능 지원

### 안드로이드 태블릿 (영상 재생 담당)
- 안드로이드 10.0 이상
- 레노버 탭 P11 이상 권장
- 블루투스 기능 지원
- 유튜브 앱 설치 또는 웹 브라우저 접근 가능

## 3. 앱 설치 방법

### 아이폰 설치
1. App Store에서 "BobCam" 앱을 검색합니다.
2. "다운로드" 버튼을 탭하여 앱을 설치합니다.
3. 설치가 완료되면 앱을 실행합니다.
4. 초기 설정 시 카메라 및 블루투스 접근 권한을 허용합니다.

### 안드로이드 태블릿 설치
1. Google Play 스토어에서 "BobCam" 앱을 검색합니다.
2. "설치" 버튼을 탭하여 앱을 설치합니다.
3. 설치가 완료되면 앱을 실행합니다.
4. 초기 설정 시 블루투스 접근 권한을 허용합니다.

## 4. 기기 연결 방법

1. 두 기기의 블루투스 기능을 활성화합니다.
2. 아이폰에서 BobCam 앱을 실행하고 "카메라" 탭으로 이동합니다.
3. 안드로이드 태블릿에서 BobCam 앱을 실행합니다.
4. 아이폰 앱에서 "태블릿 검색" 버튼을 탭합니다.
5. 연결이 성공하면 두 기기 모두에 연결 성공 메시지가 표시됩니다.

## 5. 앱 사용 방법

### 아이폰 앱 사용법
1. 카메라가 아이의 얼굴을 잘 볼 수 있도록 위치시킵니다.
2. "카메라" 탭에서 아이의 식사 행동이 실시간으로 분석됩니다.
3. 아이가 식사를 하면 녹색 표시와 함께 "아이가 밥을 먹고 있어요" 메시지가 표시됩니다.
4. 아이가 식사를 하지 않으면 빨간색 표시와 함께 "아이가 밥을 먹고 있지 않아요" 메시지가 표시됩니다.
5. 식사 상태는 자동으로 안드로이드 태블릿에 전송됩니다.

### 안드로이드 태블릿 앱 사용법
1. 앱 실행 후 유튜브 영상 ID 또는 URL을 입력하여 아이가 보고 싶은 영상을 설정합니다.
2. 아이폰에서 분석된 식사 상태에 따라 영상이 자동으로 재생되거나 일시정지됩니다.
3. 아이가 식사를 하면 영상이 재생되고, 식사를 멈추면 영상이 일시정지됩니다.
4. "기기 검색" 버튼을 탭하여 연결이 끊어진 경우 재연결할 수 있습니다.

## 6. 문제 해결

### 연결 문제
- 두 기기의 블루투스가 활성화되어 있는지 확인합니다.
- 두 기기가 서로 가까이 있는지 확인합니다(10m 이내 권장).
- 앱을 재시작하고 연결 과정을 다시 시도합니다.

### 얼굴 인식 문제
- 충분한 조명이 있는 환경에서 사용합니다.
- 카메라가 아이의 얼굴을 정면으로 볼 수 있도록 위치를 조정합니다.
- 아이의 얼굴이 카메라 프레임 안에 완전히 들어오도록 합니다.

### 영상 재생 문제
- 인터넷 연결 상태를 확인합니다.
- 유튜브 앱이 최신 버전인지 확인합니다.
- 유효한 유튜브 영상 ID 또는 URL을 입력했는지 확인합니다.

## 7. 향후 개선 사항

BobCam 앱은 지속적으로 개선될 예정이며, 다음과 같은 기능이 추가될 계획입니다:

1. 캐릭터 기반 인터페이스: 화면 가장자리에 위치한 캐릭터가 아이와 상호작용하며 식사를 독려합니다.
2. 크레딧 적립 시스템: 식사 시간에 따라 크레딧을 적립하여 영상 시청 시간을 관리합니다.
3. 식사 데이터 분석: 아이의 식사 패턴을 기록하고 분석하여 부모에게 인사이트를 제공합니다.
4. 다양한 식사 환경 지원: 다양한 조명 조건과 식사 환경에서의 인식 성능을 향상시킵니다.
